What RoleSpace is

RoleSpace is a working prototype, offered so people can evaluate it.

  • The demo uses a made-up company, FirstRound, its made-up people and a sample codebase.
  • Features, limits and access can change or stop at any time.
  • Access to the workspace is by invitation and can be withdrawn.

Acceptable use

  • Use the demo to evaluate RoleSpace, not for production work.
  • Don't enter personal, confidential or unlawful content.
  • Don't try to reach systems or data you weren't given access to, or to overload the service.
  • If you find a security problem, report it on GitHub without the details of how to exploit it, and give us time to fix it.

AI output

Answers and suggested changes come from AI models and can be wrong. RoleSpace checks that every citation points to lines that were actually read, but that doesn't prove the answer is right. Review anything before relying on it. Changes reach a repository only as pull requests, reviewed by a person.
