      How we calculate this

      Hours handed back = people using Ask and Suggest × questions a week × 48 weeks × developer minutes per question, plus small changes a month × 12 × developer minutes per change. Running cost = the app, gateway, database and sign-in at list price (about $1,300 a year) plus model calls at about 1¢ a question and 3¢ a change, measured on Gemini Flash. The live counter spreads the yearly value over 48 working weeks of 40 hours. Developers' own coding speed-up isn't counted.

      FAQ

      Questions buyers ask.

      Does our code leave our cloud?

      RoleSpace runs in your own Google Cloud project. Your repositories are read there, and models are called through Vertex AI in the same project. A model from outside Google Cloud is only used if an admin switches it on with your own key.

      Do designers and PMs need GitHub accounts?

      No. Their changes are opened as pull requests on their behalf, in their name, and they follow checks and reviews inside RoleSpace. Code owners review in GitHub as usual.

      How do we stop runaway AI spend?

      Every call uses the person's own key, with a monthly budget and per-minute limits. A total cap covers all AI together, and a project-wide hard stop can cut billing before a set amount.

      How do we add people?

      An admin adds a person by work email and picks their level, projects, models and budget. RoleSpace creates their key and logs it. Directory sync with Entra ID or Okta is on the roadmap.
