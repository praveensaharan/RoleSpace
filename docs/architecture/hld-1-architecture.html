RoleSpace · High-level design · 1 of 4 · Architecture (as built, 17 Oct 2026)

Every model call goes through one gateway

What runs today on Google Cloud. The RoleSpace app and the LiteLLM model gateway run on Cloud Run; Coder workspaces run on a VM in a private subnet with no public IP, reached only through an IAP tunnel. People sign in with Google through IAP on an HTTPS load balancer. Only the gateway's service account may call Gemini, and every call is charged to the person's own key. The demo codebase is praveensaharan/firstround-demo. Dashed parts are designed but not built: Entra ID sync, Model Armor and Cloud KMS.
